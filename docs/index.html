TurboWarp-AR

TurboWarp-AR provides camera-source based AR session and target-state blocks for TurboWarp projects.

Requirements

  • Load turbowarp-camera-source before this extension.
  • Enable TurboWarp's unsandboxed extension option.
  • Use HTTPS or another browser secure context for real camera input.

Quick start

create AR scene with camera [default] layer [above-stage]
define AR target [marker-1]
attach selector [#card] to AR target [marker-1]
set AR target [marker-1] visible [true] confidence [1]

A-Frame integration

A-Frame is optional. Attached selectors receive visible, position, rotation, data-ar-target, and data-ar-confidence attributes.

Development

See the repository README and architecture documentation for build, test, release, and compatibility details.

create AR scene with camera [CAMERA_ID] layer [LAYER]

Starts an AR session by acquiring a shared camera-source camera lease.

Block type: COMMAND. Opcode: createARScene. Permanent link

ArgumentTypeDefault valueMenu choices
CAMERA_IDSTRINGdefault
LAYERSTRINGabove-stage

LAYERを固定フォームで編集します。数値は有限数値の完全なJSON表記を使用し、範囲と静的な関連入力を検証します。enumは既知候補から選択します。未変更の空白・大小文字・数値表記は原文を保持し、reporterは評価しません。対象外の入力は変更しません。 GUIのDialogs/FixedInputsは起動時既定OFFです。有効にして再読込すると利用できます。
