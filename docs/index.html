TurboWarp-AR

TurboWarp-AR provides camera-source based AR session and target-state blocks for TurboWarp projects.

Requirements

  • Load turbowarp-camera-source before this extension.
  • Enable TurboWarp's unsandboxed extension option.
  • Use HTTPS or another browser secure context for real camera input.

Quick start

create AR scene with camera [default] layer [above-stage]
define AR target [marker-1]
attach selector [#card] to AR target [marker-1]
set AR target [marker-1] visible [true] confidence [1]

A-Frame integration

A-Frame is optional. Attached selectors receive visible, position, rotation, data-ar-target, and data-ar-confidence attributes.
